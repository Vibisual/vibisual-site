Install and first run

Install the Claude CLI first and confirm that claude resolves on your PATH. Vibisual launches every session through it.

Installers

Every release ships a Windows installer, macOS builds for Apple Silicon and Intel, and a Linux AppImage. Download the one for your system and run it. The 0.1.x preview builds are unsigned, so Windows SmartScreen and macOS Gatekeeper ask for confirmation the first time.

From source

Node 20 or newer, pnpm for the workspace.

$ git clone https://github.com/Vibisual/vibisual.git
$ cd vibisual && pnpm install
$ node scripts/runapp.mjs

# pnpm build:win → dist/Vibisual-<version>-setup.exe

First run

Vibisual writes a managed hook block into ~/.claude/settings.json and keeps a timestamped backup of the previous file beside it. Hooks outside the managed block are left untouched.

Set VIBISUAL_SKIP_HOOK_INSTALL=1 to wire the hooks yourself. The app then only receives events from sessions you have configured.
